# Power BI Projects

This repository contains Power BI projects focused on data analysis, business intelligence, and data visualization.

The goal is to demonstrate practical approaches to transforming raw data into actionable business insights through data modeling, DAX calculations, and interactive dashboards.

## Technologies & Tools

- **Power BI Desktop** – Data modeling, reporting, and visualization
- **Power Query (M)** – Data extraction, cleaning, and transformation
- **DAX** – Business metrics and analytical calculations
- **TMDL / PBIP** – Source control-friendly Power BI project formats
- **Git & GitHub** – Version control and collaboration

## Repository Structure

Projects are organized into separate directories, with each folder containing its respective Power BI project files and documentation.

## How to Open a Project

1. Clone or download this repository.
2. Navigate to the desired project directory.
3. Open the `.pbip` file using Power BI Desktop.
4. Update data source connections if necessary.
5. Refresh the semantic model to load the data.

## Version Control

This repository uses Git to track changes in Power BI reports and semantic models. Temporary files, local configurations, and sensitive datasets are excluded through `.gitignore`.

## Notes

Some projects may require access to external datasets or configuration of local data sources.

Each project may include additional documentation covering its objectives, metrics, and implementation details.
